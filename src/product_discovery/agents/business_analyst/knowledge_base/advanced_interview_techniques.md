# Advanced Interview Techniques — Intelligence-Grade Discovery

> Kompilacja technik z psychologii klinicznej, wywiadu FBI/CIA, negocjacji zakładników
> i badań behawioralnych. Cel: wyciągać PRAWDZIWE dane omijając social desirability bias.

---

## FUNDAMENTALNA ZASADA

> "Prawdziwy insight pochodzi z tego, co ludzie ZROBILI w przeszłości,
> nie z tego, co MÓWIĄ że zrobią w przyszłości."

Twój rozmówca chce być miły. Będzie dawał odpowiedzi, których Twoim zdaniem oczekujesz.
Twój zadanie: ominąć ten filtr i dotrzeć do faktów behawioralnych.

## TECHNIKA 1: Tactical Empathy (Chris Voss — FBI Hostage Negotiation)

### Mirroring
Powtórz ostatnie 2-3 słowa z pytającą intonacją, po czym zamilknij na 5-7 sekund.

```
Respondent: "Nasze procesy są naprawdę... skomplikowane."
Ty: "...skomplikowane?"
Respondent: "Tak, bo mamy trzy systemy które nie rozmawiają ze sobą i..."
              [kontynuuje z detalami których nie ujawniłby na bezpośrednie pytanie]
```

Dlaczego działa: Cisza jest dyskomfortowa. Rozmówca wypełnia ją.

### Labeling (Etykietowanie emocji)
Nazwij emocję którą widzisz zanim zadasz pytanie:

```
✅ "Wygląda na to, że ta sytuacja jest naprawdę frustrująca..."
   → Rozmówca potwierdza i rozszerza, lub koryguje → zawsze dostajesz więcej

❌ "Czy to jest dla ciebie frustrujące?"
   → Odpowiedź tak/nie → koniec
```

### Calibrated Questions (tylko "Co" i "Jak", nigdy "Czy")
```
❌ "Czy próbowałeś alternatywnych rozwiązań?"
✅ "Jak próbowałeś rozwiązać ten problem do tej pory?"
✅ "Co sprawia, że to jest trudne?"
✅ "Co musiałoby się stać, żebyś zdecydował się na zmianę?"
```

Unikaj "Dlaczego?" — brzmi jak oskarżenie i wyzwala defensywność.

### Accusation Audit (przed trudnym pytaniem)
Wyprzedź potencjalne obawy rozmówcy:
```
"Pewnie wydaje się, że pytam o to żeby coś sprzedać — ale naprawdę
chcę zrozumieć koszt tego problemu. Ile szacujesz że kosztuje Cię to rocznie?"
```

## TECHNIKA 2: Motivational Interviewing (Miller & Rollnick — psychologia kliniczna)

### Model OARS

**O — Open questions:** Tylko pytania otwarte, bez możliwości odpowiedzi tak/nie.
```
❌ "Czy jesteś zadowolony z obecnego narzędzia?"
✅ "Jak wygląda twój typowy dzień, gdy korzystasz z [narzędzia]?"
```

**A — Affirmations:** Potwierdzaj bez oceniania, sygnalizując że słuchasz:
```
"To brzmi jak naprawdę skomplikowana sytuacja do zarządzania."
"Widać, że bardzo zależy Ci na tej kwestii."
```

**R — Reflective listening:** Parafrazuj z dodaną warstwą emocjonalną:
```
Prosta refleksja: "Mówisz, że to zajmuje trzy godziny miesięcznie."
Złożona refleksja: "Słyszę, że ten czas to nie tylko zmarnowane godziny —
                   to też poczucie chaosu którego nie możesz kontrolować."
```

**S — Summarizing:** Zbierz wątki i odzwierciedl:
```
"Pozwól, że upewnię się, że dobrze rozumiem: masz problem A,
próbowałeś rozwiązać go przez B i C, ale żadne nie zadziałało,
bo [przyczyna]. Czy to dobrze ujmuję?"
```

### Change Talk vs. Sustain Talk
Słuchaj uważnie jakie sygnały daje rozmówca:

**SUSTAIN TALK** (nie jest gotowy, problem nie jest palący):
- "Obecne narzędzia są OK, po prostu trzeba się przyzwyczaić."
- "Tak naprawdę to nie jest duży problem, dajemy radę."
- Tryb warunkowy: "Gdybym miał więcej czasu..."

**CHANGE TALK** (problem jest realny i palący):
- "Już myślałem żeby coś zmienić..."
- "Ostatnio przez to straciłem [konkretna strata]..."
- "Muszę coś z tym zrobić, bo..."

Gdy słyszysz Change Talk — AMPLIFIKUJ przez pytanie:
```
"Wspomniałeś że ostatnio przez to straciłeś [X]. Co to dla Ciebie znaczyło?"
```

## TECHNIKA 3: Cognitive Interview (FBI — rekonstrukcja zdarzeń)

Opracowana w 1984, zwiększa dokładność wspomnień o 35-40% vs. standardowe pytania.

### Context Reinstatement (odtworzenie kontekstu)
Poproś rozmówcę żeby mentalnie wrócił do zdarzenia:
```
"Chciałbym, żebyś wrócił myślami do tamtej sytuacji.
Gdzie byłeś? Co robiłeś? Z kim rozmawiałeś? Jak się wtedy czułeś?
Opowiedz mi o tym momencie, gdy problem po raz pierwszy był naprawdę uciążliwy."
```

Dlaczego działa: Aktywuje szczegóły niedostępne przy bezpośrednim pytaniu.

### Report Everything (raportuj wszystko)
```
"Opowiedz mi o tym, nawet jeśli wydaje Ci się że pewne rzeczy są nieistotne
lub nie związane z moim pytaniem. Czasem najcenniejsze informacje ukrywają się
w detalach, które wydają się oczywiste."
```

### Recall in Different Order (wspominanie od końca)
```
"Teraz opowiedz mi o tym od momentu gdy zdecydowałeś [X] —
i cofnij się do momentu, gdy po raz pierwszy zauważyłeś problem."
```

### Change Perspective (zmiana perspektywy)
```
"Jak by to wyglądało z perspektywy Twojego klienta/szefa/partnera?
Co by on powiedział, że jest Twoim głównym problemem z tym procesem?"
```

## TECHNIKA 4: CIA Elicitation (zbieranie informacji przez konwersację)

Celem jest unikanie bezpośrednich pytań, które mogą wzbudzić defensywność.

### Deliberate False Statement (celowo błędne stwierdzenie)
```
"Słyszałem, że większość firm w tej branży radzi sobie z tym przez Excel i emaile..."
→ Rozmówca odruchowo koryguje: "Nie, my mamy dedykowane narzędzie, ale..."
→ Dostajesz prawdziwą informację przez korektę, nie pytanie
```

### Bracketing (zakreślanie widełek)
```
"Inne firmy z którymi rozmawiałem szacują koszt tego problemu od 50K do 500K rocznie.
 Gdzie jesteś Ty?"
→ Rozmówca koryguje do konkretnej liczby
```

### Naivete / Feigning Ignorance (udawana naiwność + wyniesienie na piedestał)
```
"Nie jestem ekspertem w waszej branży — czy możesz mi wytłumaczyć jak to działa?"
→ Ekspert chętnie wyjaśnia i ujawnia więcej niż planował
```

Wariant wzmocniony — **Feigning Ignorance** (eksploatacja ego):
```
"Mam wrażenie, że jesteś ekspertem w tej dziedzinie. Skąd ta specjalizacja?"
→ Rozmówca wchodzi w narrację — ego zaspokojone = naturalny przepływ informacji
```

### Oblique Reference (odniesienie skośne)
Omówienie tematu pozornie zewnętrznego, ale analogicznego do problemu rozmówcy:
```
"Słyszałem, że firmy z Waszej branży często mają problem z integracjami..."
→ Rozmówca używa własnego kontekstu jako punktu odniesienia i ujawnia szczegóły
```

### Quid Pro Quo (wzajemność)
Najpierw podziel się czymś wartościowym:
```
"Rozmawiałem już z 15 firmami w tej branży i widzę, że wspólnym problemem jest...
 Czy to pasuje do waszej sytuacji?"
→ Rozmówca czuje obowiązek wzajemności — dzieli się swoim kontekstem
```

### Hooks (haczyki wspólnoty)
Identyfikacja wspólnych doświadczeń, zainteresowań lub wartości na otwarcie:
```
Np. wspólny kraj/branża/konferencja → tworzy poczucie "peer, nie badacz"
→ Wychodzi się ze schematu "przesłuchujący–przesłuchiwany"
```

## TECHNIKA 4b: Sekwencjonowanie i Struktury Pytań

### Metoda Klepsydry (Hourglass Method)
Trójfazowa struktura ukrywająca cel wywiadu:

```
FAZA 1 — SZEROKA (5-10 min):
Ogólne, łagodne pytania → uśpienie czujności, ustalenie norm zachowania rozmówcy
"Jak wygląda Twój typowy tydzień pracy?"

FAZA 2 — WĄSKA (cel wywiadu, 10-15 min):
Ukierunkowane pytania na temat docelowy
"W październiku mieliście duże wdrożenie — jak to wyglądało od środka?"

FAZA 3 — SZEROKA powrót (5 min):
Rozluźnienie, rozmówca nie rozumie co był główny cel
"Wróćmy do codzienności — co planujesz w Q2?"
```

Dlaczego działa: Rozmówca nie rozpoznaje momentu wydobycia kluczowych informacji.
**Bonus:** Tuż po zwężeniu, w fazie powrotu do ogółu, padają najszczersze refleksje.

### Metoda Lejka (Funnel — dedukcyjny)
```
1. NARRACJA OTWARTA: "Opowiedz mi wszystko co pamiętasz o tamtej sytuacji."
   → Nie przerywaj przez minimum 90 sekund

2. KLARYFIKACJA: "Mówiłeś o X — możesz powiedzieć więcej o tym momencie?"

3. WĄSKIE PYTANIA: Uzupełnianie konkretnych luk (kto, co, gdzie, kiedy, jak)
   → Dopiero teraz pytania zamknięte
```

### SUE — Strategic Use of Evidence (Strategiczne Użycie Dowodów)
Kontr-intuicyjna technika śledcza: **NIE pokazuj dowodów na początku**.

```
KROK 1: Zbierz swobodną relację bez ujawniania co wiesz
KROK 2: Jeśli relacja jest niespójna — konfrontuj punkt po punkcie:
         "Mówiłeś X, ale mam tu Y..."
KROK 3: Zmuszasz rozmówcę do tworzenia kolejnych alibi
KROK 4: Alibi wpadają w sprzeczność → paraliż decyzyjny → prawda
```

Zastosowanie w discovery: Jeśli masz dane analityczne (np. z Hotjar że użytkownicy porzucają
onboarding w kroku 3) — nie mów o tym od razu. Najpierw zapytaj "Jak wygląda Twój onboarding?"
i porównaj deklarację z danymi.

## TECHNIKA 5: Laddering (Reynolds & Gutman 1988)

Docieranie do głębokich wartości przez wielokrotne "Dlaczego to ważne?".
Prowadzi od cech produktu do osobistych wartości.

```
Pytanie: "Dlaczego wybrałeś to rozwiązanie?"
Odpowiedź: "Bo jest szybkie."

Probe: "Co daje Ci ta szybkość?"
Odpowiedź: "Oszczędzam czas."

Probe: "Co robisz z tym zaoszczędzonym czasem?"
Odpowiedź: "Mogę skupić się na ważniejszych sprawach."

Probe: "Co to dla Ciebie znaczy — skupić się na ważnych sprawach?"
Odpowiedź: "Czuję że mam kontrolę nad swoim dniem."

Probe: "Co daje Ci poczucie kontroli?"
Odpowiedź: "Spokój. I satysfakcję że robię dobro dla klientów."
                         ↑
                   PRAWDZIWA WARTOŚĆ: spokój + bycie dobrym dla klientów
```

Użyj do: definiowania value proposition, messaging, feature prioritization.
Limit: max 20-30 minut techniki w jednym wywiadzie.

## TECHNIKA 6: PEACE Model (UK Police — struktura wywiadu)

Systematyczne podejście do przeprowadzania wywiadu:

### P — Preparation
- Zdefiniuj 3-5 hipotez do testowania (nie więcej)
- Przygotuj pytania otwierające bez zdradzania kierunku badań
- Zbierz publiczne dane o rozmówcy i jego firmie

### E — Engage and Explain
- Zacznij od pytania neutralnego o kontekst pracy rozmówcy
- Wyjaśnij cel bez ujawniania hipotezy:
  "Chcę zrozumieć jak działają firmy jak Wasza — bez żadnej agendy sprzedażowej."

### A — Account, Clarify and Challenge
- Pozwól opowiedzieć historię BEZ przerywania
- Następnie klaryfikuj: "Mówiłeś o X — możesz powiedzieć więcej?"
- Challenge ostrożnie: "Wspomniałeś że to działa dobrze — a kiedy NIE działa?"

### C — Closure
- "Czy jest coś ważnego o czym nie rozmawialiśmy?"
- Podsumuj to co usłyszałeś (bez swojej interpretacji)

### E — Evaluation (po wywiadzie)
- Co się potwierdziło? Co obaliło hipotezy?
- Jakie nowe pytania się pojawiły?

## SEKWENCJA WYWIADU — Master Script (45 minut)

### ETAP 1: RAPPORT (5 min)
```
"Zanim zaczniemy — opowiedz mi o sobie i swojej pracy.
Co robisz w typowy wtorek rano?"
[Tylko słuchaj, stosuj Mirroring przy ciekawych wątkach]
```

### ETAP 2: MAPPING CURRENT REALITY (10 min)
```
"Jak wygląda Twój proces [obszar który badamy]?"
"Co zajmuje Ci nieproporcjonalnie dużo czasu?"
"Co w tym jest najbardziej uciążliwe?"
[Stosuj Labeling gdy widzisz emocje: "Wygląda jakby to było frustrujące..."]
```

### ETAP 3: EXCAVATING SPECIFIC STORIES (15 min)
```
[Cognitive Interview: Context Reinstatement]
"Opowiedz mi o konkretnym razie, gdy ten problem był najbardziej uciążliwy.
 Kiedy to było? Gdzie byłeś? Co się dokładnie wydarzyło?"

"Co dokładnie zrobiłeś żeby to rozwiązać?"
"Co poszło nie tak?"
"Jak to wpłynęło na Twój dzień/projekt/klientów?"
[Minimum 5-7 sekund ciszy po każdym pytaniu — CZEKAJ]
```

### ETAP 4: ECONOMICS AND FORCES (10 min)
```
[Accusation Audit przed]
"Pewnie wydaje się to dziwne pytanie, ale chcę zrozumieć prawdziwy koszt...
 Ile szacujesz że ten problem kosztuje Cię rocznie — czas plus potencjalne straty?"

[Forces Diagram]
"Co sprawiło że zacząłeś myśleć o szukaniu czegoś lepszego?" [PUSH]
"Gdyby istniało idealne rozwiązanie — jak by wyglądało?" [PULL]
"Co powstrzymuje Cię przed zmianą obecnego podejścia?" [ANXIETY + HABIT]
"Co prawie zatrzymało Cię przed zmianą TERAZ?" [Timing - dlaczego TERAZ?]
```

### ETAP 5: NETWORK AND CLOSE (5 min)
```
[Laddering — ostatni raz]
"Gdyby ten problem znikł — co byś zrobił z odzyskanym czasem/pieniędzmi?"

[Network]
"Kto jeszcze w Twojej sieci ma podobny problem?"
"Gdybyś miał opisać ten problem komuś innemu — jak byś go opisał?"
[→ Dostają Ci copywriting prosto od użytkownika]
```

## SYGNAŁY WERBALNYCH I NIEWERBALNYCH — Cognitive Load Analysis

Kłamstwo jest gigantycznym wysiłkiem intelektualnym. Nowoczesna elicytacja opiera się
na **obciążeniu poznawczym (Cognitive Load)** — kłamca zdradza się w momencie gdy
jego mózg nie nadąża z tworzeniem spójnej narracji.

### Sygnały PRAWDZIWEGO przekazu
- Gesty rąk, mimika i słowa **w idealnej synchronizacji** (brak opóźnienia)
- Brak idealnej chronologii — pamięć epizodyczna jest asynchroniczna i chaotyczna
- Spontaniczne detale których nie pytałeś ("i wtedy moja koleżanka weszła z kawą...")
- Szczery śmiech angażuje mięśnie wokół oczu (duchenne smile — niekontrolowane)

### Sygnały ODPOWIEDZI Z GRZECZNOŚCI / KŁAMSTWA
- **Echolalia:** Powtarza słowa z pytania: "Czy zjadłeś ciastko?" → "Nie zjadłem ciastka"
- Zbyt płynna, zbyt logiczna narracja bez zakłóceń
- Wodolejstwo omijające fakty — obawa przed ciszą
- Górna część ciała "zastyga" w bezruchu
- Frazy asekuracyjne: "Szczerze mówiąc...", "Przyrzekam...", "Prawdę mówiąc..."

### Sygnały RACJONALIZACJI POST-HOC
- Eufemizmy zamiast konkretów: "niedogodność" zamiast "straciliśmy klienta"
- Odpowiedź zbyt dobrze pasuje do "idealnego klienta" — social desirability
- Brak spójników — mózg nie radzi sobie z łataniem kłamstw w długich strukturach zdań
- Dystansowanie: "ta kobieta" zamiast imienia, "ten produkt" zamiast nazwy

## RED FLAGS — Zatrzymaj wywiad i zmień podejście

| Sygnał | Interpretacja | Reakcja |
|--------|---------------|---------|
| "To brzmi świetnie!" (bez konkretów) | Social desirability bias | Labeling: "Wygląda jakby coś konkretnego przemawia..." |
| "Kupiłbym to jeśli..." | Tryb warunkowy = brak commitment | "Opowiedz o ostatnim razie gdy..." (wróć do przeszłości) |
| "Zazwyczaj...", "Generalnie..." | Ogólnik zamiast historii | "Kiedy konkretnie? OSTATNI raz?" |
| Ty mówisz >50% czasu | Pitchujesz, nie badasz | Zamilknij, zadaj otwarte pytanie, czekaj 7 sek |
| Brak historii z przeszłości | Problem nie jest realny | CI: Context Reinstatement |
| Rozmówca zmienia temat | Test szczerości — Klepsydra | Świadoma pauza, nie podążaj za zmianą |
| Rozmówca rozkojarzony/zajęty | Bariery poznawcze za wysokie | Odczekaj — znajdź moment osłabionej czujności |

## NLP: Budowanie Rapport

### Pacing (dopasowanie) → Leading (prowadzenie)
1. Match tempo mówienia i energię rozmówcy (5-10 min)
2. Po zbudowaniu rapport — subtelnie zwolnij lub zmień temat
3. Jeśli rozmówca podąża za Tobą → rapport jest zbudowany

### Predikaty (system reprezentacyjny)
Dopasuj język do stylu rozmówcy:
- Wzrokowcy: "widzę", "jasne", "perspektywa" → używaj metafor wizualnych
- Słuchowcy: "słyszę", "brzmi", "rezonuje" → metafory dźwiękowe
- Kinestetycy: "czuję", "ciężar", "solidne" → metafory dotykowe
