# OKR Structure

**Author:** Christina Wodtke  
**Source:** "Radical Focus"

---

## Formula

```
Objective (inspiring, qualitative)
├─ Key Result 1 (measurable, outcome-based)
├─ Key Result 2 (measurable, outcome-based)
└─ Key Result 3 (measurable, outcome-based)
```

---

## Good Example

```
Objective: Become the fastest onboarding in our category

Key Results:
- Time to first value < 5 minutes (currently 15)
- Activation rate > 70% (currently 45%)
- Onboarding NPS > 50 (currently 20)
```

---

## Bad Example

```
Objective: Improve onboarding

Key Results:
- Ship new onboarding flow (to jest output, nie outcome!)
- Conduct 10 user interviews (to jest activity!)
- Update documentation (to jest task!)
```

---

## Quality Checks

### Good Objective

- [ ] Inspiring (team chce to osiągnąć)
- [ ] Qualitative (nie liczba)
- [ ] Time-bound (quarter/year)
- [ ] Ambitious (stretch goal)

### Good Key Results

- [ ] Measurable (konkretna liczba)
- [ ] Outcome-based (nie activities)
- [ ] Achievable but ambitious (60-70% confidence)
- [ ] Clear finish line (wiesz kiedy done)

---

## Pro Tip

> "If you're hitting 100% of your OKRs, you're not being ambitious enough." - Google

**Meaning:** OKRs powinny być stretch goals. Osiągnięcie 70-80% to sukces.
